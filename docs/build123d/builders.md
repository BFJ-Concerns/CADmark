# Builders

Builders are stateful context managers that enable a design history-like interface where state is tracked and structured. Each dimension is distinct, and operations are aware of pending faces and edges from Build contexts with location transformations applied to all child objects.

build123d provides three primary builders:

- **BuildLine** - Create one-dimensional objects (curves)
- **BuildSketch** - Create two-dimensional objects (sketches)
- **BuildPart** - Create three-dimensional objects (parts)

## BuildLine

BuildLine is a Python context manager used to create one-dimensional objects with length but no area. These are typically used as part of a BuildSketch sketch or a BuildPart path.

### Basic Functionality

```build123d
with BuildLine() as example_1:
    Line((0, 0), (2, 0))
    ThreePointArc((0, 0), (1, 1), (2, 0))
```

The objects and operations within the context contribute to the object being created, accessed as `example_1.line`.

### Position At Operator (@)

The `@` operator identifies fractional positions along a line's length (0 to 1 scale):

```build123d
with BuildLine() as context:
    l1 = Line((0, 0), (2, 0))
    arc = ThreePointArc(l1 @ 0, l1 @ 0.5 + (0, 1), l1 @ 1)
```

The `@` operator takes a float (or integer) between 0 and 1 and determines a position at that fractional position along the line's length. `l1 @ 0.5` finds the centre of `l1`.

### Tangent At Operator (%)

The `%` operator establishes tangential constraints for smooth curve connections:

```build123d
with BuildLine() as context:
    l2 = Line((2, 0), (2, 2))
    arc = JernArc(start=l2 @ 1, tangent=l2 % 1, radius=0.5, arc_size=90)
```

This enables fully parametric designs that capture design intent.

### BuildLine to BuildSketch

BuildLine objects transfer to BuildSketch when the BuildLine context exits within a BuildSketch scope. The BuildSketch operations `make_face` or `make_hull` transform the line edges into faces:

```build123d
with BuildSketch():
    with BuildLine():
        # Define complex curves
        ...
    make_face()  # Convert edges to face
```

### BuildLine to BuildPart

BuildLine objects can create paths for BuildPart sweep operations:

```build123d
with BuildPart() as part:
    with BuildSketch():
        Circle(radius)

    with BuildLine() as path:
        # Define curved/straight segments
        ...

    sweep()  # Sweep section along path
```

### Working on Other Planes

BuildLine accepts a single Plane parameter. By default it uses Plane.XY (global coordinates):

```build123d
with BuildLine(plane=Plane.YZ) as context:
    Line((0, 0), (2, 0))
```

**Three key rules for alternate planes:**

1. BuildLine accepts a single Plane (unlike other builders accepting multiple workplanes)
2. Tuple values like `(1, 2)` are localised to the current workplane. Vector values are global.
3. Values generated by the `@` operator are global and not localised.

## BuildSketch

BuildSketch is a Python context manager for creating 2D planar objects (featuring area but no volume) that serve as profiles for 3D operations like extrude and revolve.

### Basic Functionality

```build123d
with BuildSketch() as sketch:
    Circle(radius)
    Rectangle(width, height, mode=Mode.SUBTRACT)
```

The sketch is accessed via `sketch.sketch`. Sketches consist of filled shapes combined using modes: ADD, SUBTRACT, INTERSECT, REPLACE, and PRIVATE.

### Multi-Plane Sketching

BuildSketch allows sketching on any plane while working in local X, Y coordinates:

```build123d
with BuildSketch(plane=Plane.XY, plane=Plane.YZ) as context:
    Circle(1)  # On both planes
    with Locations((5, 0)):
        Rectangle(1, 1)
```

The designer works on a virtual "drafting table" (Plane.XY) and the completed sketch applies to specified workplanes. This eliminates manual positioning calculations.

### Local vs. Global Sketches

BuildSketch internally creates sketches on Plane.XY:
- `.sketch_local` displays the local version
- `.sketch` shows the sketch as applied to target workplanes

### Feature Positioning

Features within sketches are positioned using Location contexts:

```build123d
with BuildSketch() as sketch:
    with GridLocations(x_spacing=10, y_spacing=10, x_count=3, y_count=3):
        Circle(1)
```

Positioning options:
- **GridLocations** - Rectangular grid
- **HexLocations** - Hexagonal grid
- **Locations** - Arbitrary sequences
- **PolarLocations** - Radius and angle-based

## BuildPart

BuildPart is a Python context manager for creating three-dimensional objects with volume, typically representing finished parts.

### Basic Functionality

```build123d
with BuildPart() as part:
    Box(length=10, width=10, height=10)
    Cylinder(radius=2, height=5, mode=Mode.SUBTRACT)
```

The resulting object is accessed via `part.part`.

### Implicit Parameters

BuildPart maintains internal tracking of pending objects to enable implicit parameter usage:

```build123d
with BuildPart() as part:
    with BuildSketch():
        Circle(radius)
    extrude(amount=height)  # Implicitly uses the sketch
```

For sketches, the planes they were constructed on are maintained in internal data structures to support operations like extrusion without explicit specification.

### Units

build123d doesn't assign inherent units to parts. When exporting to STL or STEP, dimensions are interpreted as millimetres. Predefined scaling constants are available:

```build123d
MM = 1
CM = 10 * MM
M = 1000 * MM
IN = 25.4 * MM
FT = 12 * IN
THOU = IN / 1000
```

Example usage:

```build123d
with BuildPart() as part:
    Box(10 * CM, 10 * CM, 5 * CM)  # 10cm cube, 5cm tall
```

### Common BuildPart Operations

```build123d
with BuildPart() as part:
    Box(10, 10, 10)

    # Add a cylinder
    Cylinder(radius=2, height=15)

    # Subtract a hole
    with Locations((2, 2, 0)):
        Hole(radius=1, depth=5)

    # Fillet edges
    fillet(part.edges(), radius=0.5)

    # Chamfer sharp edges
    chamfer(part.edges().filter_by(lambda e: e.length < 2), size=0.2)
```

### BuildPart with BuildLine and BuildSketch

BuildPart can contain BuildLine and BuildSketch contexts, which automatically transfer to the part:

```build123d
with BuildPart() as part:
    with BuildSketch():
        Circle(1)
        Rectangle(2, 2, mode=Mode.SUBTRACT)
    extrude(amount=5)

    with BuildLine() as path:
        Line((0, 0, 5), (0, 0, 15))

    with BuildSketch():
        Circle(0.5)

    sweep()  # Uses pending path and sketch
```

## Builder Context Managers

All builders use the `with` statement pattern:

```build123d
with BuildPart() as part:
    # Operations here contribute to the part
    Box(10, 10, 10)

# part.part is now the resulting 3D object
```

Builders can be nested for complex designs:

```build123d
with BuildPart() as assembly:
    with BuildSketch():
        Circle(5)
    extrude(10)

    with Locations((0, 0, 15)):
        Box(10, 10, 10)
```

## Key Features

- **State tracking**: Builders maintain state between operations
- **Implicit parameters**: Pending objects automatically used by operations
- **Location context**: Objects automatically positioned using Location contexts
- **Feature selection**: Built-in methods to select and manipulate features
- **Constraints**: Support for positional and tangential constraints (BuildLine)
- **Multi-plane support**: Sketch on any plane in local coordinates
